# 🎓 Nesne Tabanlı Programlama (OOP) Dönem Projeleri

Bu depo, İstanbul Kültür Üniversitesi (İKÜ) Bilgisayar Programcılığı bölümü Nesne Tabanlı Programlama dersi kapsamında geliştirilen otomasyon projelerini içermektedir.

## 🚀 Proje İçerikleri
Bu depo içerisinde iki farklı otomasyon projesi bulunmaktadır:
1. **Dijital Kütüphane Yönetim Sistemi:** Kitap stok takibi, üye kaydı ve ödünç alma işlemlerini nesne tabanlı mimari ile yöneten sistem.
2. **Online Kurs Platformu:** Öğrenci kaydı, eğitmen atamaları ve kurs kontenjan takiplerini içeren yönetim paneli.

## 🛠️ Kullanılan Teknolojiler
* **Dil:** Python 3
* **Arayüz (GUI):** Tkinter (Özel renk paleti ve grid sistemi ile 3 sütunlu modern Dashboard tasarımı)
* **Veritabanı:** SQLite (İlişkisel tablolar, Primary Key kısıtlamaları ve JOIN sorguları kullanıldı)

## 💡 OOP Prensipleri
Projelerde sınıflar (`Class`), yapıcı metotlar (`__init__`), kapsülleme (Encapsulation) ve hata yönetimi (`try-except`) aktif olarak kullanılmıştır. Veri manipülasyonları (stok ve kontenjan düşme gibi) doğrudan sınıfların içindeki metotlar üzerinden güvenli bir şekilde yapılmaktadır.
